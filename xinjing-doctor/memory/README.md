# 长程陪伴记忆目录

本目录仅由"心镜博士"Skill 自身读写，用于 Step 4 记忆锚点机制。

## 文件位置

- 用户记忆文件：`memory/users/<user_hash>.md`
- `<user_hash>` 由 `scripts/draw.py --mode hash --user-id <ID>` 生成；无法确认稳定用户标识时使用 `anonymous`。

## 文件格式（追加式，只存心理信息）

```markdown
# 用户记忆（匿名化）

## 会话记录

### YYYY-MM-DD
- 核心关键词：工作价值感、自我怀疑
- 防御机制：习惯自责、过度理智化
- 进步轨迹：开始为自己的边界发声
```

## 隐私红线

- 不记录用户真实姓名、单位、联系方式等身份信息。
- 不记录对话原文与隐私细节，只存心理层面摘要。
- 用户明确要求删除记忆时，立即删除对应文件并告知。
